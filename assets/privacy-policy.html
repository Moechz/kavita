Kavita Reading Server — Privacy Policy

本文档为双语隐私政策。英文版在前，中文版在后。（This document is bilingual: English first, Chinese below.）

1. Overview

Kavita Reading Server is a digital library that runs entirely on your own NAS device (TerraMaster TOS 7). The TOS package publisher (Moechz) does not collect, transmit, or share any personal data: no analytics operated by the publisher, no telemetry, no tracking, and no advertising SDKs. All your books, comics, accounts and reading data stay on your device.

2. Data stored on your device

DataLocationPurpose
User accounts (usernames, hashed passwords, roles, age ratings)/var/lib/kavita/kavita.dbMulti-user access control for your library
Library metadata, reading progress, bookmarks, reading lists/var/lib/kavita/kavita.dbLibrary state and cross-device progress sync between your own users
Covers, thumbnails, cache and application logs/var/lib/kavita/ (covers/, cache/, logs/)Serving your library in the browser
App configuration and JWT signing key/var/lib/kavita/appsettings.jsonServer settings (loopback port, base URL, email); the key signs login sessions
Your media filesThe library folders you choseYour content — the app never modifies or uploads the source files

This data stays on your device. It is never uploaded by the package publisher.

3. Upstream anonymous usage statistics (and how to disable)

The upstream Kavita project collects anonymized, non-personal usage statistics (such as an install ID, application version and OS information) to help improve the software. This is a feature of the upstream application, sent to the upstream project's statistics endpoint (stats.kavitareader.com) — it is not operated by, and not accessible to, the package publisher.

  • Disable: open the web UI as admin → Server Settings → Analytics and turn analytics off at any time.
  • The statistics contain no filenames, no library content, no account data and no personally identifiable information.

4. Other network access (user-initiated only)

  • Email (optional): if you configure an SMTP server in Server Settings → Email, Kavita sends library invitation/password-reset emails through that server. The destination and region are those of your chosen mail provider.
  • OPDS / web reader: served only on your LAN through the TOS web route /kavita/; the backend listens on loopback only and exposes no external port.
  • Nothing else: the app makes no other outbound connections by default, and sends no data to Moechz or any Moechz-operated server.

5. Accounts and children

Accounts are created by you (the first visitor runs the setup wizard and becomes admin; further users are invited by the admin). Passwords are stored hashed. Age-rating and restricted profiles let parents control content for children; the service itself is a LAN application.

6. Your rights: access, correction, deletion

  • Access: use the web UI (user settings, reading history), or read the files listed above directly on the NAS.
  • Correction: edit users, libraries and settings in the web UI at any time.
  • Deletion: remove users/content in the UI; apt remove kavita (or TOS App Center uninstall) keeps /var/lib/kavita, apt purge deletes it. Your media source files are never touched.

7. Changes and contact

This policy ships inside the application package and is served at /kavita/privacy-policy.html on your device. Upstream project: https://github.com/Kareadita/Kavita. TOS packaging issues: https://github.com/Moechz/kavita (Issues).

Kavita Reading Server — 隐私政策（中文）

1. 概述

Kavita Reading Server 是完全运行在您自己的 NAS 设备（TerraMaster TOS 7）上的数字图书馆。TOS 打包发布者（Moechz）不收集、不传输、不共享任何个人数据：无发布者运营的统计、无遥测、无跟踪、无广告 SDK。您的书籍、漫画、账号与阅读数据全部保留在设备上。

2. 存储在您设备上的数据

数据位置用途
用户账号（用户名、哈希后的密码、角色、适龄分级）/var/lib/kavita/kavita.db图书馆的多用户访问控制
库元数据、阅读进度、书签、阅读清单/var/lib/kavita/kavita.db库状态与您自己用户间的进度同步
封面、缩略图、缓存与应用日志/var/lib/kavita/（covers/、cache/、logs/）在浏览器中呈现您的图书馆
应用配置与 JWT 签名密钥/var/lib/kavita/appsettings.json服务器设置（回环端口、子路径、邮件）；密钥用于登录会话签名
您的媒体文件您指定的库目录您的内容——应用从不修改或上传源文件

以上数据全部保留在设备上，发布者不会上传任何内容。

3. 上游匿名使用统计（及关闭方法）

上游 Kavita 项目会收集匿名的、非个人的使用统计（如安装 ID、应用版本、操作系统信息）用于改进软件。这是上游应用自身的功能，数据发送到上游项目的统计端点（stats.kavitareader.com）——不由发布者运营，发布者也无法访问。

  • 关闭方法：以管理员打开网页界面 → 服务器设置（Server Settings）→ 分析（Analytics），随时关闭统计。
  • 统计内容不包含文件名、库内容、账号数据或任何个人可识别信息。

4. 其他网络访问（仅由您主动配置触发）

  • 邮件（可选）：若您在 服务器设置 → 邮件 中配置了 SMTP 服务器，Kavita 会通过该服务器发送图书馆邀请/密码重置邮件。数据去向为您所选邮件服务商的基础设施。
  • OPDS / 网页阅读器：仅通过 TOS 标准路由 /kavita/ 在局域网内提供服务；后端仅监听本机回环，不对外暴露任何端口。
  • 除此之外：应用默认无其他对外连接，也不向 Moechz 或任何 Moechz 运营的服务器发送数据。

5. 账号与未成年人

账号由您创建（首位访问者通过向导成为管理员，其他用户由管理员邀请）。密码以哈希形式存储。适龄分级与受限账户可帮助家长控制未成年人可见内容；本服务是局域网应用。

6. 您的权利：访问、更正、删除

  • 访问：使用网页界面（用户设置、阅读历史），或直接在 NAS 上读取上述文件。
  • 更正：随时在网页界面修改用户、库与设置。
  • 删除：在界面中删除用户/内容；apt remove kavita（或 TOS 应用中心卸载）保留 /var/lib/kavita，apt purge 会删除；库目录中的媒体源文件不受影响。

7. 变更与联系

本政策随应用包分发，并在您设备上通过 /kavita/privacy-policy.html 提供。上游项目：https://github.com/Kareadita/Kavita；TOS 打包问题：https://github.com/Moechz/kavita（Issues）。
